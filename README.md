# 🎬 Verdant Cinema

**Discover stories that stay with you.**

Verdant Cinema is a modern, responsive movie discovery website built with a premium black and neon-green colour palette. It allows users to explore movie posters, search for films, filter by genre, and view movie details through a clean and cinematic interface.

This project is designed for movie discovery only. **It does not stream or play movies on the website.**

## ✨ Features

- **Modern Homepage** — Cinematic hero section with an elegant dark theme.
- **Movie Collection** — Browse movie posters with titles, ratings, release years, and descriptions.
- **Search Functionality** — Search movies by title, year, or genre.
- **Genre Filters** — Explore movies by Action, Comedy, Horror, Sci-Fi, Drama, and Romance.
- **Movie Details** — View descriptions, cast information, ratings, release dates, and genre details.
- **Trailer Links** — Find movie trailers through YouTube.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Smooth Animations** — Subtle hover effects and transitions for a polished experience.
- **Keyboard Support** — Use keyboard shortcuts and controls for easier navigation.
- **No Backend Required** — Runs directly in a web browser without a database or API key.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- TMDB image URLs for movie posters

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and an internet connection for loading remote poster images and fonts.

### Installation

1. Clone the repository:

   ```zsh
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```zsh
   cd verdant-cinema
   ```

3. Open `index.html` in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

## 🎨 Design Philosophy

Verdant Cinema follows a minimal, cinematic design approach featuring:

- Deep black and forest-green backgrounds.
- Neon-green highlights and interactive elements.
- Clean typography and consistent spacing.
- Carefully arranged movie poster cards.
- Responsive layouts and subtle animations.

The goal is to make discovering movies feel simple, immersive, and visually engaging.

## 🔍 How It Works

1. Browse the movie collection on the homepage.
2. Search for a movie using the search bar.
3. Select a genre to filter the collection.
4. Click a movie poster to view its details.
5. Use the trailer link to find the movie trailer on YouTube.

## 🖼️ Movie Posters

Movie posters are loaded from remote TMDB image URLs. Their availability depends on the external image service and an active internet connection.
